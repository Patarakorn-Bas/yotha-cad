# โยธาแคด — คู่มือติดตั้ง (v7.2)

เขียนแบบอาคาร 2D/3D รูปตัด รูปด้าน แผ่นงานพร้อมกรอบชื่อแบบ แบบขยายเหล็กเสริม และส่งข้อมูลไป Civil Toolkit
ใช้งานออฟไลน์ได้หลังติดตั้ง และซิงก์ระหว่างคอมกับ iPad ผ่าน Google Drive ของคุณเอง

## ส่วนที่ 1 ขึ้นเว็บด้วย GitHub Pages (ทำครั้งเดียว)

1. เข้า GitHub กด **New repository** ตั้งชื่อ `yotha-cad` เลือก **Public** แล้วกด Create
2. กด **uploading an existing file** ลาก 6 ไฟล์นี้ขึ้นไป (ต้องอยู่ชั้นนอกสุด ไม่อยู่ในโฟลเดอร์ย่อย)
   `index.html` `three.min.js` `manifest.json` `sw.js` `icon-192.png` `icon-512.png`
   แล้วกด **Commit changes** (SyncCode.gs และ README.md ไม่ต้องอัปโหลดก็ได้)
3. ไปที่ **Settings → Pages** ช่อง Branch เลือก `main` และ `/ (root)` กด Save
4. รอ 1–2 นาที แล้วเปิด `https://patarakorn-bas.github.io/yotha-cad/`
   ใต้ชื่อแอปมุมซ้ายบนต้องขึ้น **v7.2**

## ส่วนที่ 2 ติดตั้งเป็นแอป

- **คอมพิวเตอร์ (Chrome หรือ Edge):** กดปุ่ม **ติดตั้งแอป** ด้านบนของแอป หรือไอคอนติดตั้งในช่องที่อยู่เว็บ
- **iPad:** เปิดลิงก์ใน **Safari** → ปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม**

หลังเปิดออนไลน์ครั้งแรก ใช้งานแบบออฟไลน์ได้ (ยกเว้นการซิงก์)

## ส่วนที่ 3 ซิงก์ระหว่างคอมกับ iPad (ทำครั้งเดียว)

ข้อมูลเก็บใน Google Drive ของคุณ โฟลเดอร์ `โยธาแคด Sync` พร้อมสำเนาสำรอง 20 ครั้งล่าสุดในโฟลเดอร์ `backups`

1. เปิด https://script.google.com กด **New project**
2. ลบโค้ดเดิมทั้งหมด แล้ววางโค้ดจากไฟล์ **SyncCode.gs**
3. แก้บรรทัด `var SECRET = 'CHANGE-ME-ตั้งรหัสของคุณเอง';` เป็นรหัสของคุณ เช่น `var SECRET = 'ycad-2026-xyz';`
4. กด **Deploy → New deployment** เลือกชนิด **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
   กด Deploy แล้วอนุญาตสิทธิ์ (ถ้าขึ้นหน้าเตือน ให้กด Advanced → Go to project)
5. คัดลอก **Web app URL** (ขึ้นต้น https://script.google.com/macros/s/ ลงท้าย /exec)
6. เปิดแอปบน **เครื่องที่มีงานอยู่แล้ว** กดปุ่ม **ซิงก์** ด้านบน วางลิงก์ ใส่รหัสซิงก์ (ตรงกับ SECRET)
   กด **ทดสอบการเชื่อมต่อ** แล้วกด **ส่งข้อมูลขึ้นคลาวด์**
7. บนเครื่องที่สอง ใส่ลิงก์และรหัสเดียวกัน แล้วกด **ดึงข้อมูลจากคลาวด์**
8. ติ๊ก **ซิงก์อัตโนมัติ** ทั้งสองเครื่อง แอปจะส่งขึ้นหลังแก้ไข 12 วินาที และตรวจของใหม่ทุกครั้งที่เปิดแอป

> ถ้าแก้งานพร้อมกันสองเครื่อง ฉบับที่ส่งทีหลังจะทับฉบับก่อน กู้คืนได้จากโฟลเดอร์ `backups` ใน Google Drive
> ถ้าย้ายข้อมูลจากเวอร์ชันทดลองบน claude.ai ให้กด ซิงก์ → สำรองเป็นไฟล์ ในหน้าเดิม แล้วไปกด เปิดไฟล์สำรอง ในแอปที่ติดตั้ง

## อัปเดตเวอร์ชันใหม่

อัปโหลดไฟล์ชุดใหม่ทับของเดิมใน repository เดิม ข้อมูลในเครื่องไม่หาย
แอปจะขึ้นแถบ "มีเวอร์ชันใหม่พร้อมใช้งาน" ให้กดโหลดใหม่
